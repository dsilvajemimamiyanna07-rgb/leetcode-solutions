## Problem: Reverse String (Easy)
**Link:** https://leetcode.com/problems/reverse-string/

### Approach
Used a two-pointer approach starting from both ends of the character array and swapping characters inward until the pointers meet.

### Complexity
- Time: $O(n)$
- Space: $O(1)$

### Notes
In-place modification allows $O(1)$ extra memory space.
